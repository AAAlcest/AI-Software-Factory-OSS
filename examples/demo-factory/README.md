# Demo Factory

This directory will contain a fully synthetic example Factory used to teach the framework without exposing any real operating history.

Planned fictional scenario:

- organization: Example Corp;
- projects: Project Atlas and Project Beacon;
- Human role: Factory Director;
- primary management AI: Deputy Factory Director;
- separate Governance and Runtime AIs;
- project-specific Project Primary agents.

The demo will illustrate role assignment, Staff Offices, Project Rooms, Issue meetings, PR Candidate Change Envelopes, correspondence CC, portfolio Console visibility, Wardrobe work-session records, state/evidence updates, handoff/succession and Human gates.
