# AI Software Factory skill contracts

These directories define portable skill contracts for the V1.1 cockpit layer. They are implementation-neutral reference material: copying a `SKILL.md` file does not install a product feature, grant authority or connect an external account.

Use them with [the Skills layer design](../docs/SKILLS_LAYER.md) and [Project cockpit design](../docs/CHATGPT_PROJECT_COCKPIT.md).

Available contracts: `factory-overview`, `project-overview`, `role-overview`, `project-recovery`, `role-recovery`, `handoff`, `factory-health`, and `task-packaging`.
