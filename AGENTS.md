# AGENTS.md

This repository is an AI Software Factory framework.

Before acting:

1. Read `AI_ENTRYPOINT.md`.
2. Treat repository current state and explicit authority as stronger than chat memory.
3. Distinguish technical identity (GitHub account, token, tool) from Factory authority (role + scope).
4. Do not infer Human-only, security, production, destructive, release, credential, external-company, or publication authority.
5. Do not copy private operating history into examples. Use synthetic data.
6. If authority, environment, state, or trust boundary is unknown, fail closed and record the unknown instead of guessing.

A role title is not authority by itself. A chat/session is not a durable organizational identity by itself.
