# Management Office

Synthetic Staff Office for portfolio/product coordination.

Recommended surface: ChatGPT.

Durable facilities in this example:

- `inbox/` — canonical addressed work;
- `outbox/` — sender references, not duplicate bodies;
- `desk/CURRENT.md` — rolling recovery cursor;
- `pending/` — unresolved work;
- `wardrobe/` — optional Work/Codex invocation receipts;
- `handoffs/` — true-succession archive only.

This Office has no real appointment or private Factory authority.
