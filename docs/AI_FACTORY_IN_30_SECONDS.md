# AI Factory in 30 Seconds

A Human leads the Factory. AI agents occupy logical roles with explicit authority scopes. Projects are durable entities with their own state and correspondence endpoints. Chats and coding sessions are temporary operators, not the source of truth.

```text
Human intent
  -> management / project authority
  -> Issue discussion when deliberation is needed
  -> implementation branch
  -> PR Candidate Change Envelope
  -> evidence + role-specific review
  -> integration
  -> current-state readback
```

Core rules:

- repository current truth beats chat memory;
- role title does not create authority;
- technical credential does not create organizational authority;
- `To` owns action, `CC` owns visibility only;
- Project Primary owns project execution unless explicitly reassigned;
- Console sees the portfolio but does not automatically execute;
- Wardrobe records execution-session transitions;
- finalized handoff records are immutable history;
- same-incumbent recovery is not succession;
- privacy is structural and deny-by-default.
