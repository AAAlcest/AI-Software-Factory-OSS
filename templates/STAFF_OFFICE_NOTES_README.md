# Staff Office Notes

Status: non-authoritative event-driven delta history.

- No daily reporting obligation.
- Create a note only for meaningful changed work/evidence/blocker/next-action state.
- `YYYY-MM-DD.md` is optional date grouping, not a heartbeat requirement.
- Compare current canonical work/evidence with the last applicable note and record
  only deltas.
- Link Issue/PR/Project/Git/evidence instead of copying whole threads.
- Do not put secrets or credentials here.
- `../CURRENT.md` remains the concise mutable cursor.
- `../pending/` remains the unresolved queue.
- Notes never grant authority or replace current state/evidence/gates.

See the framework's `docs/STAFF_OFFICE_NOTES.md` when available.
