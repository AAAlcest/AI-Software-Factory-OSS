# Skill: project-overview

Purpose: summarize one project's current operating picture.

Inputs: project ID or Project Room pointer.

Read: Project Room/state, current Issue/PR when material, Project Primary/authority pointer, relevant evidence and only the Office CURRENT records needed for related roles.

Output: repository, Project Primary, status, ref/SHA, active Issue/milestone, pending, blockers, candidate/review state, evidence refs, related roles, Human gates and next safe action.

Do not copy the whole Factory into the output. Unknown authority or conflicting current state blocks the affected action.
